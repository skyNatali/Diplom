Проект содержит комплексную систему автоматизированного тестирования для Кинопоиска, включающую UI-тесты, API-тесты и smoke-тесты. Разработан в рамках дипломной работы по автоматизации тестирования.

    ## Запуск тестов

    ### UI-тесты
    pytest tests/ -m ui -v

    ### API-тесты
    pytest tests/ -m api -v

    ### Smoke-тесты
    pytest tests/ -m smoke -v

    ### Все тесты
    pytest tests/ -v
