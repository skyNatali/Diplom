## Особенности тестирования Кинопоиска

### Проблема капчи
Кинопоиск активно использует защиту от ботов, поэтому при частых запросах может появляться капча.
Это нормальное поведение для сайта и не является ошибкой тестов.

### Стратегии обхода:
1. Увеличенные таймауты между действиями
2. Упрощенные тесты с минимальным количеством действий
3. Пропуск проверок при обнаружении капчи
4. Скриншоты при падении для анализа

### Ограничения:
- Не рекомендуется запускать тесты чаще 1 раза в 5 минут
- Тесты могут падать из-за капчи - это ожидаемое поведение
- Для стабильной работы требуется ручное вмешательство при капче
